Installer le carnet

Installée, l'app s'ouvre en plein écran, sans barre d'adresse, et reste utilisable sans connexion.

Les données sont stockées séparément sur chaque appareil. Pour les transférer, utilise « Sauvegarde complète » puis « Restaurer une sauvegarde ».

Synchroniser entre appareils

Le carnet n'utilise ni compte ni serveur : tes données ne quittent pas l'appareil. Deux façons de retrouver les mêmes chiffres partout :

Fichier de sauvegarde — exporte le .json, range-le dans iCloud Drive, restaure-le sur l'autre appareil. Gratuit, immédiat, aucun compte.
Compte en ligne — connexion Google ou Apple et base hébergée, pour une synchronisation automatique. Le fichier SYNC.md du dépôt décrit l'implémentation complète.

Tant qu'aucun serveur n'est configuré, le carnet reste entièrement hors-ligne : c'est le mode actuel.
